# AI model comparison

## Candidate models
- OpenVoice V2
- XTTS-v2
- F5-TTS

## Current recommendation
OpenVoice V2 is the primary production choice because it is open source, commercially usable, efficient on GPU, and well-suited for a user-facing voice cloning app. XTTS-v2 remains the best multilingual fallback. F5-TTS is useful for experiments and research, but its official non-commercial weights limit direct product deployment without additional licensing evaluation.
